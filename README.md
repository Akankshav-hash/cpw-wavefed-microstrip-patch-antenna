# Wideband CPW-Fed Microstrip Antenna Design for 5G using MATLAB

## Overview

This project focuses on the design and simulation of a **Wideband Coplanar Waveguide (CPW)-Fed Microstrip Patch Antenna** using MATLAB. The antenna is optimized for wireless communication applications and provides enhanced bandwidth, stable radiation characteristics, and compact size suitable for modern communication systems.

## Features

* Wideband CPW-fed microstrip antenna design
* MATLAB-based simulation and analysis
* Return Loss (S11) analysis
* Radiation pattern visualization
* Compact and low-cost antenna structure
* Suitable for WLAN, Bluetooth, IoT, and 5G applications

## Tools & Technologies

* MATLAB
* Antenna Toolbox
* Electromagnetic Simulation

## How to Run

1. Open MATLAB.
2. Load the project files.
3. Run the antenna design script.
4. Analyze the generated S11 plots and radiation patterns.
